# Computación Gráfica

> Repositorio virtual para publicar los trabajos, ejercicios y proyectos del curso de **Computación Gráfica**.

---

## Descripción

Este repositorio contiene todos los entregables desarrollados a lo largo del curso, incluyendo trabajos individuales, ejercicios de práctica semanal y proyectos finales. El objetivo es documentar el proceso de aprendizaje y aplicar los conceptos vistos en clase.
