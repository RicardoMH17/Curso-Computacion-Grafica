# 🎨 Computación Gráfica

> Repositorio virtual para publicar los trabajos, ejercicios y proyectos del curso de **Computación Gráfica**.

---

## 📋 Descripción

Este repositorio contiene todos los entregables desarrollados a lo largo del curso, incluyendo trabajos individuales, ejercicios de práctica semanal y proyectos finales. El objetivo es documentar el proceso de aprendizaje y aplicar los conceptos vistos en clase.

---

## 🗂️ Estructura del Repositorio

```
computacion-grafica/
│
├── 📁 01_trabajos/              # Trabajos individuales del curso
│   ├── trabajo_01/
│   │   ├── src/                 # Código fuente
│   │   ├── assets/              # Imágenes, texturas, modelos
│   │   ├── output/              # Capturas o renders de resultado
│   │   └── README.md            # Descripción del trabajo
│   ├── trabajo_02/
│   └── trabajo_N/
│
├── 📁 02_ejercicios/            # Ejercicios de práctica por semana
│   ├── semana_01/
│   ├── semana_02/

│
├── 📁 03_proyectos/             # Proyectos finales
│   ├── proyecto_01/
│   └── proyecto_final/
│
├── 📁 04_recursos/              # Material de apoyo
│   ├── referencias.md
│   └── utilidades/
│
├── .gitignore
└── README.md
```

---

## 🚀 Cómo navegar este repositorio

Cada carpeta de trabajo o proyecto contiene su propio `README.md` con:

- **Descripción** del ejercicio o trabajo
- **Herramientas y tecnologías** utilizadas
- **Instrucciones** para ejecutar el proyecto
- **Capturas de pantalla** o renders del resultado
